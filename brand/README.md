# Yanti — sistema de marca oficial

Este paquete contiene la reconstrucción vectorial de la variante **B Organic**, confirmada como master oficial de `yanti.app` el 8 de agosto de 2026.

## Uso rápido

- Interfaz clara: `svg/yanti-lockup-horizontal-dark.svg` o `svg/yanti-domain-lockup-dark.svg`.
- Interfaz oscura: `svg/yanti-lockup-horizontal-light.svg` o `svg/yanti-domain-lockup-light.svg`.
- Isotipo desde 32 px: `svg/yanti-isotype-color.svg`.
- Isotipo a 16 o 24 px: `svg/yanti-isotype-micro-color.svg`.
- Favicon/PWA: carpeta `icons/`.
- Variables de interfaz: carpeta `tokens/`.
- Reglas completas: `docs/YANTI_BRAND_GUIDELINES.md`.
- Accesibilidad: `docs/YANTI_ACCESSIBILITY_REPORT.md`.

Los wordmarks están convertidos a contornos vectoriales: no dependen de una fuente instalada. Nunito se incluye con su licencia OFL para futuras piezas de comunicación.

## Principio de implementación

Los colores vivos del logo son colores de identidad, no colores de texto en fondos claros. Para botones, enlaces, foco y estados se deben usar los derivados accesibles definidos en los tokens.
